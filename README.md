# 府城微醺地圖 🍸 TainanBarHop

**網站：** https://ychsiao-tw.github.io/TainanBarHop/

以「好的我願意台南民宿」為預設起點，探索臺南酒吧、找附近店家、安排續攤路線，並透過 Google Maps 步行導航。

## 功能介紹

- 臺南酒吧互動地圖、36 間精選店家與 OpenStreetMap 公開酒吧點位
- 民宿、GPS、輸入地址或地圖選點作為起點
- 店名／街道／類型搜尋、附近 1／2／5／10 公里篩選與直線距離
- 酒吧資訊、收藏、智慧隨機抽店及排除已造訪店家
- 續攤清單、直線距離路線排序、路線分享與逐站導航
- 手機底部導覽與「今晚開喝」逐站操作模式
- OSM 座標和臺南市政府門牌參考座標自動比較（管理檢視）

資料來自 © OpenStreetMap contributors 與臺南市政府開放門牌資料；座標僅供參考，並非店家入口或即時營業保證。請先核對營業狀態，飲酒勿酒駕。
