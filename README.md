# 府城微醺地圖 JS v6.1

**網站：** https://ychsiao-tw.github.io/TainanBarHop/

以臺南「好的我願意台南民宿」為預設起點的手機酒吧探索網站。可更換起點、搜尋精選酒吧、抽店、規劃續攤與開啟 Google Maps 步行導航。

## 功能
- 自製 Canvas 互動地圖、酒吧圖釘與清單連動
- 36 間精選酒吧，加上 OSM 公開點位（ArcGIS Feature Service / Overpass 多來源備援）
- 店名／街道／酒種即時搜尋，收藏與篩選
- 以已確認座標計算直線距離、附近 1／2／5／10 公里查找
- 未定位的精選酒吧可透過 Photon 逐間查詢候選座標、人工確認或在地圖手動選點，保存於此瀏覽器
- 隨機抽酒吧、排序續攤站點、分享及步行導航

距離不是步行路程。公開 OSM 點位可能缺漏或已歇業，實際店家資訊請再確認。Google Maps 資料沒有被爬取或存入本網站。

資料來源：© OpenStreetMap contributors（ODbL）；ArcGIS Online 公開 OSM Asia Amenities 圖層；Photon / komoot（僅依使用者單次操作查詢地址）。網站需要網路讀取公開點位與地圖底圖；已確認的精選座標和公開點位快取會儲存在目前裝置。

飲酒勿開車、騎車。請年滿 18 歲再飲酒。
