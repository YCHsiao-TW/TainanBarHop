# 府城微醺地圖 🍸 TainanBarHop v7.1

**網站：** https://ychsiao-tw.github.io/TainanBarHop/

從「好的我願意台南民宿」或自訂位置出發，探索臺南酒吧、搜尋附近店家、安排與分享續攤行程。

## 功能介紹
- 臺南酒吧互動地圖、精選酒吧與 OpenStreetMap 公開酒吧資料
- 起點切換、附近 1／2／5／10 公里搜尋、直線距離、分類與收藏
- 自動排序：最近鄰＋2-opt 局部改善，從起點出發；尚未定位的店排在最後（route.js）
- 店家資訊面板：類型、地址、原有特色描述、定位品質、Google Maps 店家搜尋與步行導航；不顯示未核實的營業時間、評分或價格
- 智慧抽店：可選附近／全部、調酒／啤酒／餐酒、排除已造訪或已加入續攤店家
- 今晚開喝模式：逐站導航、完成或跳過、上一站、回民宿
- 產生可還原的續攤分享網址；不傳送裝置 GPS／個人起點，開啟者可選擇是否取代自己的清單
- 市府門牌參考座標與 OSM 原始點位自動比對，保留座標來源與偏移差距，可檢視／匯出 CSV

門牌座標是地址參考點，不一定是店門口。公開 OSM 店家可能漏標或停業，實際營業及訂位資訊請另行確認。行程資料和收藏存在使用者目前瀏覽器，不是雲端同步。飲酒勿酒駕或騎車。

資料來源：© OpenStreetMap contributors；臺南市政府 114 年臺南市門牌坐標資料。
