# 府城微醺地圖 🍸 TainanBarHop v6.4

**網站：** https://ychsiao-tw.github.io/TainanBarHop/

以「好的我願意台南民宿」為預設起點，探索臺南酒吧、搜尋附近店家、隨機抽店、規劃續攤與開啟步行導航的手機優先網站。

## 功能介紹

- 臺南酒吧互動地圖、精選酒吧以及 OpenStreetMap 公開酒吧資料
- 從民宿、手機定位、地址或地圖選擇起點；附近 1／2／5／10 公里搜尋與直線距離
- 依店名、地址、分類搜尋，收藏與隨機抽店
- 加入續攤、調整順序、分享行程、Google Maps 步行導航
- **自動比較原始 OSM 點位與市府門牌參考座標**，顯示兩者偏移距離、可信度依據與推薦的暫用定位來源
- 自動保留雙來源座標；可查看全部店家比對結果與匯出 CSV
- 內建 35 間已配對官方門牌的精選酒吧；額外公開酒吧透過政府門牌地址索引進一步比對

門牌座標是參考點，不保證為酒吧入口；OSM 點位不保證目前仍營業。定位差異大的店家應先核對實際地址。公開點位載入失敗時，精選清單、距離和導航仍可使用。飲酒勿開車或騎車。
