# 府城微醺地圖 🍸 TainanBarHop v7.1.5

**網站：** https://ychsiao-tw.github.io/TainanBarHop/

**使用說明 / Help：** https://ychsiao-tw.github.io/TainanBarHop/help.html

臺南酒吧探索與續攤規劃網站，支援繁體中文和英文介面。語言可在頁首自由切換並記住選擇；店名和地址保留原文，方便導航搜尋。

## 功能介紹 / Features

- 臺南酒吧 Canvas 互動地圖、精選店家與 OSM 公開酒吧點位 / Interactive map, curated bars and public OSM points
- 民宿、手機 GPS、地址／地標候選確認或地圖選點作為起點 / Guesthouse, GPS, address / landmark search with confirmation, or map starting point
- 搜尋酒吧、分類、附近直線距離、收藏與智慧抽店 / Search, filters, nearby distance, favorites and random picks
- 規劃續攤、最佳化順序、分享可還原行程網址 / Plan, reorder and share bar-hop routes
- 逐站「今晚開喝」模式與 Google Maps 步行導航 / Tonight mode and walking directions
- OSM 與臺南市政府門牌資料自動座標比較 / Coordinate comparison with government doorplate reference points
- 獨立中英文使用說明頁（頁首入口）、常見問題、資料與安全提醒 / Bilingual Help, FAQ, data and safety guidance

酒吧營業資訊與座標可能變動，出發前請確認店家。距離為直線估算，不等於步行路徑。飲酒請勿開車或騎車。
