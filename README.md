# 府城微醺地圖｜Tainan Bar Hop

**網站位置：** https://ychsiao-tw.github.io/TainanBarHop/

以臺南「好的我願意台南民宿」為預設起點的手機友善酒吧探索與續攤網站。也可選擇目前位置、自訂地址或點選地圖指定起點。

## 網站功能

- **附近開喝：** 查找設定範圍內、具已確認地圖座標的酒吧，依直線距離排序。
- **酒吧搜尋：** 即時搜尋精選酒吧及已載入的 OpenStreetMap 公開點位，支援名稱、地址與類型篩選；找不到時可直接前往 Google Maps 搜尋。
- **隨機抽店：** 讓網站幫忙選擇今晚的酒吧，並可加入續攤。
- **互動地圖：** JavaScript Canvas 地圖顯示公開點位、出發地及已規劃路線；選擇地圖上的店家可以查看或加入續攤。
- **續攤規劃：** 收藏酒吧、編排與分享多站路線，提供逐站 Google Maps 步行導航。
- **公開資料擴充：** 按需求讀取 OpenStreetMap／Overpass 的酒吧點位，不需要 Google Maps API Key。

公開點位和精選清單均可能遺漏店家，營業時間與店家地址應以當日公告及 Google Maps 店家資訊確認。地圖直線距離和示意連線不是實際步行路線。喝酒不開車、不騎車。
